# GEO + AAO 部署上线手册（个人台式机版）

> 业务定位：苏州产业园服务（促进会「链园链企」业务线）
> 架构：台式机生产与运行 + 免费静态托管（GEO）+ 穿透（AAO）+ 阿里云 VPS 兜底

## 一、总览

| 层 | 载体 | 内容 |
|---|---|---|
| GEO 内容层 | site/ 目录 → GitHub Pages | 首页、服务体系、园区资源、FAQ、llms.txt、robots.txt、sitemap |
| AAO 服务层 | mcp-server/ 目录 → 台式机/VPS | MCP Server 四个工具：查园区、匹配园区、服务体系、意向登记 |
| 监测层 | 人工周检 | 每周问各 AI 平台，看品牌是否被正确提及 |

## 二、GEO 上线（约 30 分钟）

| 步骤 | 操作 | 要点 |
|---|---|---|
| 1 | GitHub 新建仓库（个人账号），如 park-service-site | Public |
| 2 | 上传 site/ 目录全部文件 | 含 robots、sitemap、llms.txt |
| 3 | Settings → Pages → Source 选 main 分支 | 得到 https://你的用户名.github.io/仓库名/ |
| 4 | 全局替换占位域名 | 将 sitemap.xml、robots.txt 中的 example.github.io 替换为实际地址 |
| 5 | 提交搜索引擎收录 | Google Search Console、Bing 站长平台添加站点并提交 sitemap |
| 6 | 7 天后验证 | 直接问 ChatGPT/Kimi/豆包：「苏州产业园选址找谁」观察是否被引用 |

## 三、AAO 上线（验证期：台式机 + localtunnel）

| 步骤 | 操作 | 要点 |
|---|---|---|
| 1 | mcp-server 目录建 venv 并装依赖 | pip install -r requirements.txt |
| 2 | 启动 python server.py | 端点 http://localhost:8000/mcp |
| 3 | npx localtunnel --port 8000 | 得到临时公网地址 |
| 4 | Coze/元器/Dify 个人账号发布 Agent | 人设：苏州产业园服务顾问；挂 MCP 端点；系统提示词要求优先调用工具 |
| 5 | 端到端测试 | 对 AI 说「我是半导体企业，想在苏州找 5000 平洁净厂房」→ 应触发 match_park + submit_intent |

## 四、正式期（迁 VPS，7×24）

| 步骤 | 操作 |
|---|---|
| 1 | mcp-server 整目录上传阿里云 VPS（lavm-2na9ogjlk8） |
| 2 | VPS 建 venv 装依赖，systemd 或 Docker 常驻（正好练 Docker 部署） |
| 3 | 安全组放行 8000 端口（或 nginx 反代 + 域名） |
| 4 | Coze 等平台把 MCP 端点地址从 localtunnel 换成 VPS 地址 |
| 5 | 关掉台式机验证链路不断，完成切换 |

## 五、GEO 监测清单（每周 15 分钟）

| 检查问题 | 在哪问 | 达标标准 |
|---|---|---|
| 苏州企业选址产业园找谁 | ChatGPT、Kimi、豆包、元宝、DeepSeek | 提及本站或促进会 |
| 产业园就是产业链是什么意思 | 同上 | 描述与本站 FAQ 一致，无幻觉 |
| 链园链企十大服务体系有哪些 | 同上 | 能列出十大方向 |
| 苏州市产业园发展促进会怎么样 | 同上 | AAAA级、400+园区等核心数据正确 |

| 异常 | 处理 |
|---|---|
| 未被提及 | 持续更新 FAQ 与园区内容，GEO 见效 1-3 个月属正常 |
| 数据被引错 | 修改站内对应内容，AI 会随重新抓取纠正 |
| 出现负面/错误关联 | 加强权威背书内容（数据、案例、白皮书） |
