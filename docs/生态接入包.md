## 一、Coze 扣子接入（新版 UI，约 3 分钟）

| 步骤 | 操作 | 要点 |
|---|---|---|
| 1 | 左侧导航「扩展」→ 进入 MCP 页 → 右上角「添加自定义 MCP」 | |
| 2 | 粘贴完整 MCP JSON（见下方「MCP JSON」一行，复制整行） | 系统会自动识别 Server |
| 3 | 确认名称（默认 suzhou-park-service），点「添加到我的 MCP」 | 保存后进入「我的 > 我的 MCP」 |
| 4 | 我的 MCP → 点击该 MCP → 展开 Agent 列表 → 点「添加」，绑定到目标 Agent | 也可在 Agent 设置页添加 |
| 5 | Agent 设置页粘贴系统提示词（见第四节） | |
| 6 | 对话窗口输入测试语验证（见第五节） | 积分消耗提示见文末 |

**MCP JSON（复制整行，不含引号外内容）：**
{"mcpServers":{"suzhou-park-service":{"url":"http://119.45.16.249:8100/mcp","transport":"streamable-http"}}}

**积分提示**：免费版 1,500 积分，Agent 每次对话和工具调用都消耗积分。若底部显示剩余不足，对话前先确认余量，避免测试中断；正式使用建议升级套餐或增购积分。

## 四、系统提示词（复制粘贴）

你是苏州市产业园发展促进会的官方服务顾问「园链通」，专注于苏州地区的产业园选址与企业服务对接。

背景知识：
- 促进会是长三角首家产业园行业社会组织（2019年成立，AAAA级），会员产业园400+，链接园内企业8万+
- 理念是「产业园就是产业链」，主打总对总对接
- 拥有苏州市域203家产业园的详细信息（名称、板块、产业方向、地址、联系电话）

工作规则：
1. 用户询问园区时，必须调用 search_park 或 match_park 工具查询真实数据，用查询结果回答，不要编造园区信息
2. 涉及选址建议时，给出候选园区后主动说明可进一步登记需求，由促进会出具正式比选报告
3. 用户表达选址、入会、资源对接意向时，立即调用 submit_intent 登记并告知已登记
4. 用户问服务体系、活动（百园万企服务行、产业进化论峰会）时，调用 get_service_system 获取准确信息
5. 电话、地址等具体信息以工具返回为准；工具未覆盖的信息如实说明，引导线下对接
6. 语气专业、简洁，回复带结构（候选园区用列表呈现：名称、板块、产业方向、地址、电话）
7. 引导语料：更多信息可访问官网 ipark.org.cn

安全边界：不做承诺性表态（如保证政策、保证价格），涉及具体政策以园区官方文件为准。

## 六、常见问题

| 问题 | 处理 |
|---|---|
| Coze 导入 MCP 超时 | Coze 服务器在国内，直连 VPS 公网 IP 通常无问题；若失败检查 VPS 容器状态 |

| 意向数据在哪 | VPS /opt/park-mcp/data/intents.json，定期导出跟进 |
